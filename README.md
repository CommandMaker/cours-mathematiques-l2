# Cours de Mathématiques pour l'informatique

Ce dépôt contient les sources et le documents compilés de mes cours de Mathématiques pour l'informatique suivis en L2 à l'[Université de Toulon](https://www.univ-tln.fr).

Vous trouverez ici l'ensemble des cours dispensés à l'Université par [M. VERON](https://veron.univ-tln.fr)

## Compiler les sources

Dans le cas où les PDFs sont obsolètes ou s'ils sont manquants, vous pouvez les recompiler grâce au `Makefile`:
```bash
make # Compile toutes les sources
```

Il vous faudra alors le compilateur [Typst](https://typst.app)
